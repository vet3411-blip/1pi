# Тихий маршрут

Статический лендинг выдуманного сервиса прогулок по Светлоречью. Город, фотографии и маршруты вымышлены; подбор — локальная демонстрация, а не реальная навигация. Данные формы никуда не отправляются.

На первом экране можно переключать атмосферу города: это меняет фотографию и заранее выбирает соответствующий уровень шума в форме. «Пауза на минуту» показывает дыхательный ритм; её можно закрыть кнопкой или клавишей Escape. Результат подбора показывает точки прогулки по порядку.

## Локально

Нужен Node.js 22+. Устанавливать зависимости не требуется.

```sh
npm run dev
npm test
npm run build
```

Предпросмотр: http://127.0.0.1:4173/quiet-route/. Для просмотра сборки: `node scripts/serve.mjs --dist`.

## GitHub Pages

1. Загрузить проект в публичный GitHub-репозиторий (для бесплатного GitHub Pages).
2. В Settings → Pages → Build and deployment выбрать Source: GitHub Actions.
3. Отправить изменения в main или master. Workflow Pages проверит подбор, соберёт сайт и опубликует папку dist.
4. Адрес опубликованного сайта появится в завершённом workflow Deploy GitHub Pages.

Сайт работает и в подпапке репозитория, и на отдельном домене благодаря относительным путям. Публикуются только HTML, CSS, JavaScript и assets. Приложение не использует API или серверные функции. Шрифт Golos Text загружается из Google Fonts; при недоступности используется Arial.

## Файлы

- `index.html`, `styles.css`, `redesign.css` — содержание и оформление. Фотографии в `assets/` оптимизированы в WebP.
- `routes.js` — каталог маршрутов и чистая функция подбора.
- `app.js` — форма, результаты и готовые варианты прогулок.
- `assets/` — локальные фотографии и favicon.
- `.github/workflows/pages.yml` — публикация GitHub Pages.

Фотографии созданы встроенным Imagegen. Промпты сохранены в `IMAGE_PROMPTS.md`.
